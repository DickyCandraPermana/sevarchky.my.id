# sevarchky.my.id

> **FROERYBELL // SEVARCHKY — Surreal Organic Dreamscape (3D Interactive)**
> Ethereal 3D WebGL Dreamscape, Amorphous Fluid Shaders, Multi-Agent Architecture, and High-Throughput Distributed Systems.

## Overview
Standalone flagship portfolio and interactive 3D WebGL spatial computing environment powered by Next.js 16 App Router, React 19, Tailwind CSS v4, and Three.js custom pearlescent shaders.

## Key Features
- **Amorphous Jelly Core**: Custom GLSL vertex noise displacement simulating organic soft-body physics in real-time.
- **Dynamic 16k Spores Engine**: Instanced particulate spore field reacting to spatial touch and mouse movement.
- **Procedural Sound Architecture**: Pure Web Audio synthesis (Tibetan singing bowls, tactile warp ripples, UI feedback) without external audio files.
- **Tactical Command Terminal (`⌘K`)**: Integrated cyber-brutalist codex with instant diagnostics, warp triggers, and palette shifting.
- **Dynamic Hardware Tiering**: Responsive particle scaling (8,000 to 16,000) and adaptive DPR throttling across mobile and desktop.

## Engineering Standards
- Next.js 16.3.8 + React 19.2.8 + TypeScript 5
- Node.js Native Test Runner (`node --test`)
- OMEGA Clearance: Zero personal identity leakage
